# NXG — Entwurf

Ein Entwurf für nxg-group.de als vollständige Website aus fünf Seiten.
Reines HTML und CSS, kein Build-Schritt: was hier liegt, ist was ausgeliefert
wird.

**Live:** https://andidatys.github.io/nxg-demo/

| Seite | |
|---|---|
| `index.html` | Startseite, im Kopf der Markenfilm |
| `fachbereiche.html` | IT, Finance, Engineering |
| `ueber-nxg.html` | Über NXG |
| `fuer-wen.html` | Für Unternehmen und für Kandidat:innen |
| `kontakt.html` | Kontakt |

`shared/` trägt Struktur und Verhalten, `theme.css` Farbe und Schrift.

Dies ist eine Entwurfsvorschau, nicht die Live-Website. Die Fotos sind
Platzhalter; der Kopf trägt einen fertigen Film aus dem Markenzeichen. Alle
Texte stammen wörtlich von nxg-group.de. Keine Seite wird indexiert: jede
trägt `<meta name="robots" content="noindex, nofollow">`.

Erzeugt aus dem privaten Arbeits-Repository; hier nicht von Hand bearbeiten.
