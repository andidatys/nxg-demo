# NXG — Entwurfsrichtungen

Sechs Entwurfsrichtungen für nxg-group.de, jede eine vollständige Website aus
fünf Seiten. Reines HTML und CSS, kein Build-Schritt: was hier liegt, ist was
ausgeliefert wird.

**Live:** https://andidatys.github.io/nxg-demo/

| Ordner | Richtung |
|---|---|
| `n1-puls/` | Dunkel und ruhig |
| `n2-vorwaerts/` | Kantig und grafisch |
| `n3-auftrieb/` | Hell |
| `n4-glut/` | Plakativ und wortkarg |
| `n5-wechsel/` | Glut, dunkel und hell im Wechsel |
| `n6-atome/` | Vorwärts, mit einem Film aus dem Zeichen im Kopf |

Jede Richtung enthält dieselben fünf Seiten — `index.html`,
`fachbereiche.html`, `ueber-nxg.html`, `fuer-wen.html`, `kontakt.html` — plus
ihre eigene `theme.css`. `shared/` trägt Struktur und Verhalten, das Theme
wählt Farbe und Schrift.

Dies ist eine Entwurfsvorschau, nicht die Live-Website. Die Fotos sind
Platzhalter; der Kopf von `n6-atome/` trägt dagegen einen fertigen Film
aus dem Markenzeichen selbst. Alle Texte stammen wörtlich von nxg-group.de. Keine Seite wird
indexiert: jede trägt `<meta name="robots" content="noindex, nofollow">`.

Erzeugt aus dem privaten Arbeits-Repository; hier nicht von Hand bearbeiten.
